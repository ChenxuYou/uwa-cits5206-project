The rubric’s own words, in all three criteria

The line is attribution, not writing

  • What keeps a section at Competent is “unclear which parts have been written by the student” — never the quality of the prose.
  • So the rule is evidence before prose: harvest the links first, write the paragraphs second. The other order invents claims you then have to hunt for.
  • One sentence, one artefact. A paragraph on “improving the costing screens” is worth less than one line naming a file and the pull request that merged it.
  • Where work was joint, say it was joint and name the other person. Five of us share one repository and the marker opens the same board we do.

[DECIDE] One naming pattern for all five PDFs, and who cross-reads whose draft on Thursday 24 September. Both now, in the room, not over chat on the 27th.

Jaswanth Vericherla

Nine working days in which evidence can still be created

Six habits worth more than six paragraphs

  • One issue per piece of work, closed by the pull request that does it. Closes #NN is the whole mechanism.
  • One branch per story, named for it. The brief asks for branches by name; us-12-proposed-rates reads as a contribution, patch-3 does not.
  • The test ships in the pull request that adds the behaviour, not in a tidy-up afterwards.
  • Review with comments, not a rubber stamp. A review that caught a real defect is the strongest single artefact for criterion three.
  • A comment at the top of anything non-obvious you wrote. The rubric asks for documentation you developed; this is the cheapest kind.
  • Do not manufacture any of it. Back-dating and splitting one commit into ten are visible in the timeline.
