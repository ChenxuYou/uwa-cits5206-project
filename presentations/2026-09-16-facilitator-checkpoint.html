ADR-002 · the sealed record as a PDF

We chose the library by reading its licence, not its API

  • The export was the only link in the M4 chain nobody had built or costed, so it was brought forward out of sprint 5 as a spike.
  • The nicest library on offer, QuestPDF, is free only below USD 1M annual revenue. UWA is not below it, and we hand this tool to UWA.
  • Choosing it would have handed the client a bill produced by our convenience, discovered after we had gone. MigraDoc, MIT licence, instead.
  • The document is built from the sealed snapshot, never from the live rows — so it cannot disagree with the record it claims to be.

A known gap, with a date on it

The schema cannot change once the client is typing into it

  • The database is currently built with EnsureCreated(), which cannot alter an existing schema.
  • Locally that costs a developer one deleted file. On staging it would cost the client's entered figures.
  • Moving to Entity Framework migrations is therefore a gate on deploying, not a tidy-up afterwards.
  • Written into the repository as a known gap on the day it was noticed, rather than discovered on 2 October.

Two decisions that are ours, and are labelled as ours

Where the client's method runs out, we say so in the code

  • Every requirement carries a source marker — client's answer, guide, workbook or our own minutes — so nothing anonymous reaches the build.
  • A multi-year cost profile is averaged into one annual figure. Their guide's example is a single year and says nothing about the rest.
  • The indirect uplift is divided back out of the revenue projection. Preserved from the spike; no client document says either way.
  • Both are commented at the line where they happen and both travel in the next question batch. An assumption nobody can find is not an assumption.

Source: src/Models/RicCycle.cs · src/CostingTool.Engine/RateEngine.cs · docs/project/plan.md §6.

Dai Lam La La

The risk register, reviewed every Saturday

The threat is not an attacker; it is a plausible wrong number

A rate is published for three to five years, embedded in grant budgets across the University, and then defended in a Freedom of Information response. A spreadsheet flags none of that: a cleared formula returns a number that looks fine.

Which is why the controls that count here are decimal arithmetic, a typed collection no range can be dragged across, the immutable snapshot with its hash, and a test that stops a merge — not a firewall.
