Hi Mathew,

Thank you again for testing the tool in all three roles and for your detailed notes. They were
really helpful, and we’re glad the capacity, rates, review and approval pages came across
clearly.

**Changes made from your feedback**

- Navigating back from Costs: there’s now a “← Back to platform” link on the costs step, and
  every completed step in the step bar is clickable, so capability names can be corrected
  without starting again.
- Editing cost items: each cost line now has an Edit option, so a line can be corrected without
  deleting it and adding it again.
- Professional staff levels: Levels 1–10 have been added alongside academic Levels A–E.
- High/low cost school: this field has been removed.
- Position funding type: “LG funded” and “GP funded” have been added.
- Salary auto-fill (partly done): you enter a base salary once, and each year of the cycle is
  filled in from it, including superannuation and an optional yearly increase. Every year stays
  editable. Filling the salary automatically from the pay level needs UWA’s current pay scales,
  so we’ve listed it as the first recommended next step.

On the approver feedback, we agree that detailed feedback is often best discussed verbally. The
return comment can then record the outcome of that conversation.

**Staging server**

The staging server was updated on 11 October and now runs the final release (v1.0.0), so you’re
welcome to try the changes. The address and logins are the same as before. Please note that test
data entered earlier didn’t carry over to the new version and will need to be re-entered.
